Security by design
  1. 01
    Data never leaves your tenant All processing happens within your IBM Cloud environment. No data is sent to third-party models or shared tenants.
  2. 02
    Role-based access control Admins define exactly what each user or team can read, write, execute, and which tools they can call.
  3. 03
    Audit logs on every action Every file edit, tool call, and command Bob executes is logged with full context — who, what, when, why.
  4. 04
    Guardrails on sensitive operations Bob will not execute destructive operations, expose secrets, or bypass permissions — even if instructed to.
  5. 05
    IBM Cloud security baseline TLS 1.3, IBM Key Protect for secrets, FIPS 140-2 compliant cryptography, and SOC 2 audit support.
