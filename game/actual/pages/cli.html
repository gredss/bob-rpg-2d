How Bob CLI works
  1. 01
    Install Bob CLI One command install via npm or direct binary download. Works on Linux, macOS, and Windows.
  2. 02
    Authenticate once Authenticate with your IBM Cloud credentials. Token stored securely — no re-auth per session.
  3. 03
    Run any task Pass instructions in natural language. Bob reads your codebase, uses tools, and outputs results inline.
  4. 04
    Pipe into CI/CD Use Bob as a CI/CD step — scan, fix, generate, or validate before your pipeline continues.
  5. 05
    Same MCP tools, same modes Every MCP integration and mode available in VS Code works identically in the CLI.
