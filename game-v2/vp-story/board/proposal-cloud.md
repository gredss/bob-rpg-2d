## 1. Executive Overview

Apex Cloud Solutions proposes a comprehensive 18-month cloud migration programme to transition your on-premise infrastructure and workloads to a managed hyperscaler environment (AWS). The programme covers infrastructure lift-and-shift, application re-platforming, and an 8-week post-migration stabilisation period.

---

## 2. Scope of Work

| Phase | Duration | Deliverable |
|---|---|---|
| Phase 1 — Discovery & Design | Months 1–3 | Infrastructure audit, migration blueprint, dependency mapping |
| Phase 2 — Pilot Migration | Months 4–7 | 3 non-critical workloads migrated and validated |
| Phase 3 — Core Migration | Months 8–14 | All production workloads migrated; DR configured |
| Phase 4 — Stabilisation & Handover | Months 15–18 | Performance tuning, runbook documentation, team training |
