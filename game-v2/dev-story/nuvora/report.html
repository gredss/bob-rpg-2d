Bad Practices Fixed — before.html → index.html

Legacy practice in before.html Resolution in index.html Technical advantage
Missing width=device-width — viewport was initial-scale=1 only Correct width=device-width, initial-scale=1.0 Configures layout correctly across all modern device viewports
Duplicate <meta name="description"> tags Single, rich SEO meta description Prevents search engine penalties, improves indexing
overflow-x: hidden on body masking broken mobile layout Fluid columns, elastic flexboxes, responsive grids Eliminates horizontal scrolling mathematically — no masking

Premium Additions Beyond the Fix List

A1 — Ambient Backlight Glows
CSS radial-gradient orbs (.glow-orb) positioned behind hero and CTA content. Creates the depth of Stripe/Vercel without any images or JS — pure CSS, zero network cost.
A2 — Interactive Cursor Spotlight
Vanilla JS mousemove listener on each .feature-card updates CSS variables --x and --y. A radial-gradient at those coordinates draws a subtle glow that tracks the cursor. ~10 lines, no dependencies.
A3 — Gradient Text Masks
Section headings and the hero h1 use background-clip: text with a white-to-violet gradient. Communicates quality without being decorative noise.
A4 — Responsive Mobile Navigation
A hamburger toggle safely controls .navbar-links and .navbar-actions display. No layout flash, no JavaScript conflicts, properly hidden on desktop via media query.
