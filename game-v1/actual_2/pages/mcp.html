IBM Bob · MCP Ecosystem LIVE

An MCP server acts as a bridge between Bob and external services — databases, APIs, or custom scripts. With MCP, you extend Bob's capabilities beyond its built-in features.

MCP provides Bob with
Tool discovery Access to available tools with their descriptions and parameters — Bob learns what it can do automatically.
Tool invocation The ability to call specific tools with arguments and receive structured responses — in context, in chat.
Resource access The capability to read live data from specific resources — without leaving your workflow.
