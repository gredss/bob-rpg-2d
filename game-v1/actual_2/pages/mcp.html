How Bob uses MCP
  1. 01
    What is MCP? Model Context Protocol is an open standard that lets Bob securely connect to external tools and data sources.
  2. 02
    Supported tools are registered Instana, DataStage, IBM BAW, custom REST APIs — each registered as an MCP server Bob can call.
  3. 03
    Bob calls the right tool Bob decides which tool to invoke based on your request, builds the call, and executes it — all in context.
  4. 04
    Results flow back into chat Tool output is interpreted, summarised, and surfaced directly in your conversation — no context switching.
  5. 05
    Full audit trail Every tool call Bob makes is logged — what was called, when, with what parameters, and what came back.
