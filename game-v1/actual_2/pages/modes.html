Built-in modes
Ask Read MCP Skill

Understand concepts or analyse existing code without making changes. Bob stays read-only — no edits, no surprises.

Best for: explaining code, answering technical questions, architecture reviews
Plan Read Edit MCP Skill

Think through architecture or create a technical plan before implementation. Bob loads the create-plan skill automatically and produces a reviewable plan.

Best for: new features, complex problems, system design, breaking down tasks
Agent Read Edit Execute MCP +5

Take your idea or plan and bring it to life. Full autonomy — reads and writes files, executes commands, calls tools, spawns subagents.

Best for: implementing features, fixing bugs, refactoring, file operations
Why it matters
01
Task specialisation Get precisely the type of assistance you need. Bob adapts its tools, permissions, and behaviour — not just its tone.
02
Safety controls Ask and Plan modes are read-only by design. No accidental file modifications when you're exploring or planning.
03
Seamless mid-task switching Bob can switch modes autonomously — moving from Plan into Agent once a plan is approved, without you having to intervene.
04
Build your own Define tool access, file permissions, and custom instructions to enforce team standards or create purpose-specific assistants.
