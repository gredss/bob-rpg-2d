How modes work
  1. 01
    Default Agent mode Bob starts in Agent mode — full autonomy, reads and writes files, executes commands, calls tools.
  2. 02
    Switch to Plan mode Bob becomes a technical lead — asks questions, researches, and produces structured plans before writing code.
  3. 03
    Switch to Ask mode Read-only, explanation-focused. Bob answers questions without modifying anything in your workspace.
  4. 04
    Specialist modes Java Modernization, Instana Installer — deep domain expertise loaded as a dedicated mode with its own skills.
  5. 05
    Custom modes Build your own mode with a custom role definition, tool permissions, and skill set — tailored to your team's workflow.
